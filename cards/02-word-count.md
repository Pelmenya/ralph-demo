## Зачем

Для подписи «N слов» под текстом нужна функция подсчёта, одинаково понимающая пробелы,
табуляции и переводы строк.

## Что сделать

- В `src/text.mjs` добавить `wordCount(text)`: слово — непустой отрезок между пробельными
  символами.

## Критерии готовности

- [ ] `wordCount('')` → `0`, `wordCount('  one  two\tthree\n')` → `3`.
- [ ] Строка из одних пробелов → `0`.
- [ ] Тесты в `test/text.test.mjs`, гейт (`npm run syntax`, `npm test`) зелёный.
