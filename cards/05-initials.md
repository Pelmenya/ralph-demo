## Зачем

Для аватаров и аббревиатур нужны инициалы.

## Что сделать

- В `src/text.mjs` добавить `initials(text)`: первый символ каждого слова в верхнем регистре, без разделителей; слово — как в `wordCount`.

## Критерии готовности

- [ ] `initials('')` → `''`, `initials('ada  lovelace')` → `'AL'`.
- [ ] Символ вне BMP не разрезается; ограничения (первая кодовая точка, а не буква; `ß` → `SS`) описаны в JSDoc.
- [ ] Тесты в `test/text.test.mjs`, гейт (`npm run syntax`, `npm test`) зелёный.
