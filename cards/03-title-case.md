## Зачем

Для заголовков нужна функция, поднимающая регистр начала каждого слова.

## Что сделать

- В `src/text.mjs` добавить `titleCase(text)`: первый символ каждого слова — заглавный,
  остальные — строчные; слово — как в `wordCount`, пробельные символы сохраняются.

## Критерии готовности

- [ ] `titleCase('')` → `''`, `titleCase('hello WORLD')` → `'Hello World'`.
- [ ] Пробельные символы сохраняются: `titleCase('  a\tb\n')` → `'  A\tB\n'`.
- [ ] Символ вне BMP не разрезается; ограничения (без учёта локали, не titlecase Unicode,
      ведущая пунктуация не меняется) описаны в JSDoc.
- [ ] Тесты в `test/text.test.mjs`, гейт (`npm run syntax`, `npm test`) зелёный.
