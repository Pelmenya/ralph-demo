# Проектная половина промпт-контракта — демо-проект

> Переносимая половина — `ralph.md` в корне дерева, её копируют из установки ядра. Этот
> файл говорит то, что верно только для демо: стек, гейт, метки.

## Стек и раскладка

- Язык и рантайм: JavaScript (ES-модули, `.mjs`), Node 24.
- Зависимостей нет: ни `dependencies`, ни `devDependencies`. Ставить ничего не нужно, и
  добавлять зависимости в задачах демо нельзя — гейт обязан не ходить в сеть.
- `src/text.mjs` — код, `test/text.test.mjs` — тесты на встроенном `node:test`.
- `cards/` — тексты карточек, из которых заведены задачи в трекере. Их не правят.

## Команды проверок

| Проверка  | Команда          | Что означает красный                                  |
| --------- | ---------------- | ----------------------------------------------------- |
| синтаксис | `npm run syntax` | `src/text.mjs` не разбирается — синтаксическая ошибка |
| тесты     | `npm test`       | упал тест: прочитай имя теста и ожидание в выводе     |

Перед завершением сессии гоняй обе.

## Конвенции кода

- Одна функция — один экспорт с JSDoc-комментарием: что принимает и что возвращает.
- Тест на каждый критерий готовности карточки, имя теста начинается с имени функции.
- Чего не делают никогда: не пишут секреты, адреса хостов и пути машины — репозиторий
  публичный.

## Допустимые метки

- `complexity:low` / `complexity:medium` / `complexity:high` / `complexity:expert` — оценка
  размера карточки, ровно одна.
- `area:lib` — код и тесты библиотеки.
- `area:docs` — README и доки.

## Площадка и трекер

Сессия в трекер НЕ ходит — она пишет намерения (см. `ralph.md`).

- Форж: SourceCraft.
- Карточку закрывает раннер по намерению `close` сессии.
