# ralph-demo

Маленький проект, на котором видно, как ралф доводит карточку от трекера до мерджа без
человека.

- `src/text.mjs` — библиотека строк; задачи добавляют в неё по функции.
- `test/` — тесты на `node:test`. Зависимостей нет, гейт в сеть не ходит.
- `cards/` — тексты двух карточек одной вехи: из них заводятся задачи в трекере.
- `.claude/ralph/` — конфиг раннера и проектная половина правил сессии.
- `.claude/settings.json` — проводка барьера сессий; сами хуки копируются из установки
  ядра.

Гейт:

```bash
npm run syntax
npm test
```

Установка ядра, заведение карточек и dry-run — по инструкции «Демо» в репозитории ядра
(`docs/demo.md`).
